# LifeTimeline

A private, serverless web app (hosted on GitHub Pages) to help people create and reflect on their
**Life Timeline** — the psychological lifeline exercise of placing life events on a time axis and
rating their emotional impact.

> ⚠️ This is a self-reflection tool, not a substitute for therapy.

- [Research notes](docs/RESEARCH.md)
- [Development plan](docs/DEVELOPMENT_PLAN.md)

All data stays in your browser. Nothing is sent to any server.
